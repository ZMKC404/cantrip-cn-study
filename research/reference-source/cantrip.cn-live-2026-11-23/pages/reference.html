按界面、交互和视觉风格翻找真实案例。

  • Recent设计灵感把网上近期的优秀设计作品集中到一处，适合每隔几天来翻翻新东西。recent.design
  • 60fps动效灵感库收集 iOS 和网页应用里的动画与交互细节，可以直接看动效是怎么做的。60fps.design
  • Collect UI界面灵感库每天整理一批界面设计与作品集，也可以订阅邮件，按分类和设计师浏览。collectui.com
  • Mobbin产品截图库收录大量真实移动端和网页应用的截图与流程，做界面调研时可以按功能检索。mobbin.com部分付费
  • Refero Styles网站风格库收集真实网站的风格，附配色、字体、间距和给 AI 读的 DESIGN.md。styles.refero.design
  • Great iOS AppsiOS 应用图库精选好看好用的 iPhone 应用，每个配一句话介绍。greatapps.fyi
  • posts.design社媒设计库整理知名公司实际发在社交平台上的帖子设计，看品牌怎么做内容。posts.design
  • OGimage.gallery分享图图库手工挑选的 OG 分享图合集，用来参考链接预览图怎么设计。ogimage.gallery
  • Supahero首屏版式库专收网站首屏（hero）区块的版式库，写落地页时用来找思路。supahero.io
  • MotionSites动效网页提示词库提供带动效的网页区块和对应的 AI 提示词，复制后可以让 AI 生成类似页面。motionsites.ai部分付费

组件与代码23 个

动画库、组件库和可直接拿来用的实现。

  • Lottie动画格式把 AE 动画导出为 JSON，在各端原生播放。lottie.airbnb.tech
  • Theatre.js动画编辑给代码里的动画配一个可视化时间线编辑器。theatrejs.com

  • Vaul抽屉组件手感很好的移动端抽屉，带速度判定与边界阻尼。vaul.emilkowal.ski
  • Sonner通知组件堆叠式 Toast 的标杆实现，本站的堆叠通知 Demo 向它致敬。sonner.emilkowal.ski
  • 21st.dev组件社区设计工程师投稿的 React 组件目录，通过 shadcn CLI 把代码装进自己的项目。21st.dev部分付费
  • beUI动效组件库可复制粘贴的动效组件，基于 Motion，另有 React Native 版本。beui.dev部分付费

  • Cuelume交互音效库给按钮、输入框、菜单配上点击音效：14 种声音用 Web Audio 实时合成，零依赖，开源。cuelume.dev
  • Libraries.dev特效库一组独立的 UI 特效 npm 包，如边缘光晕、思考球、液态金属，面向 AI 编程场景。libraries.dev部分付费
  • Bencho交互组件库可在线调参的交互式 React 组件和微交互，内容是真实运行的而非截图。bencho.dev
  • Halaska UIAI 产品 UI 套件基于 shadcn/ui 的单文件 React 套件，收录 AI 产品常见的界面和交互模式。ui.halaska.com
  • BoardUI设计系统面向仪表盘和智能体界面的 React 设计系统，85 个组件，含 19 种图表。boardui.com部分付费
  • Spectrum UI动效组件库动画组件与区块库，带 MCP 服务，可让 AI 助手直接装组件。ui.spectrumhq.in
  • Shoogle组件搜索跨多个注册源搜索 shadcn 的区块、组件和模板，省得逐个站点翻。shoogle.dev
  • Bklit UI图表组件库176 个图表组件，覆盖面积、柱状、桑基等，另有区块和在线 Studio。bklit.com
  • Canvas UIWebGL 特效库用 WebGL/WebGPU 在 HTML 内容上叠加视觉特效，支持 React、Vue、Svelte 等。canvasui.dev
  • CSS Text Effects文字特效库117 个纯 CSS 文字动画，复制即用，也附给 AI 编程助手的提示词。text-effects.colorion.co
  • Liquid Glass玻璃质感组件面向 React、网页和 Electron 的液态玻璃材质，提供 Clear 和 Regular 两种样式。liquid-glass.glassapp.dev
  • OpenTUI终端界面库用 TypeScript 写终端界面的工具包，核心为 Zig，支持 React 与 Solid。opentui.com
  • Interaction Kit交互组件库一组可复制的 React 交互细节，如图片放大、表情选择、标签页和复制反馈。interactionkit.org
  • Transitions.dev动效库Jakub Antalik 做的转场合集，43 种以上，另有 AI 构建器和动效检查工具。transitions.dev部分付费

# cantrip.cn 深度拆解报告 + 复刻说明

> 拆解方式：curl 抓取公开 HTML/CSS/JS/search.json 落盘 → 4 个并行 subagent 分别拆 HTML 结构、CSS 设计系统、详情页、JS 行为规格 → 汇总交叉验证。
> 复刻方式：**原生重实现**（自己写 HTML/CSS/JS 复现布局系统与交互机制，不搬运原站资产；卡片 artwork 全部 CSS 自绘）。

---

## 一、站点定位

**Cantrip = 收集好的 UI 设计与创意的灵感画廊**。每张卡片是一个值得拆解的 UI 作品（来自 X/Twitter 等来源），链回原作者，附「一键复制提示词」。99 个作品、6 个分类（微交互/组件/界面/移动端/创意/设计原理），中英双语（`/` zh-CN、`/en`）。

用户截图中的 mood app 是站内 `dayface-mood-faces` 作品卡（作者 rishi，720×900 竖屏视频）。**点阵背景属于该作品 artwork 内部**，cantrip 站点本身是纯暖纸色底、无任何纹理。

## 二、技术栈

| 层 | 选型 | 证据 |
|---|---|---|
| 框架 | **Astro 静态站**（无框架水合） | `/_astro/` 资源哈希、`data-astro-cid-*` scoped hash、组件脚本命名 `X.astro_astro_type_script_index_0_lang.HASH.js` |
| 水合 | **零 island、零 client:*`** | 全文无 `astro-island`；交互全部靠 6 个 `type=module` 渐进增强 |
| CSS | Tailwind v4 preflight + Astro scoped style + lightningcss 压缩 | `@layer theme,base,components,utilities`；scoped 规则形如 `.sidebar[data-astro-cid-wv7whodv]` |
| 字体 | **零 webfont，纯系统栈** | 无 `@font-face`；`-apple-system … "PingFang SC" "Hiragino Sans GB" "Microsoft YaHei"` |
| 动画 | Motion One 风格 spring/bounce（WAAPI 封装） | JS 报告：`animate(el,keyframes,{spring,bounce})` |
| 深色模式 | **无**（`color-scheme:light`） | 全站唯一 dark 是演示画布的迷你主题 `.demo-artboard[data-theme=dark]` |
| 断点 | **唯一一个：1023px** | `@media (width<=1023px)` 全包移动端适配 |

## 三、页面架构（双栏壳）

```
body
├ a.skip 跳到正文（focus 时上滑入）
├ aside.sidebar[data-sidebar]   ← position:fixed; left:var(--shell-x); width:320px
│   ├ brand：■ ● + "Cantrip" SVG path 字标（非图片）
│   ├ nav 24px 大字导航（灵感/参考/关于），aria-current 黑
│   └ foot：宣言逐词 <span.word> + 订阅/投稿 t-pill + 「已收录 99 个」
├ header.mbar（≤1023px 才显示；sticky 顶栏，滚动后 data-scrolled 出细分割线）
├ .mmenu 移动菜单（clip-path:inset 下拉展开，非侧抽屉）+ .mscrim
├ main.shell-main（margin-left:var(--content-left) 让出侧栏）
│   ├ PageHeader（h1 sr-only + statement）
│   ├ .toolbar 吸顶毛玻璃条（chips / tagpill / ⌘K 搜索 / 排序菜单）
│   └ .feed-wrap[data-feed] > .feed[data-feed-grid] > article.card ×24
├ .detail / .search / .subscribe / .feedback 四个 div-overlay 浮层（全部 hidden 初始）
└ .toaster aria-live
```

关键几何：`--shell:1520px` 大屏居中，`--shell-x:max(0px,(100vw-1520px)/2)`，侧栏挂在 shell-x 上、主区 `margin-left:calc(shell-x+rail)`。**非 grid 双栏，是 fixed + margin 让位**。

## 四、设计系统 tokens（复刻已逐字照搬）

- 暖纸色系：`--bg:#faf8f4`、`--fg:#1a1a1a`、线 `#e8e4dc/#d8d2c6`、填充 `#f3efe8`、accent **纯黑** `#1a1a1a`。
- 阴影全部是暖棕黑 `#3c2c14` 的 alpha 变体（`--shadow-card: 0 1px 2px #3c2c1408, 0 12px 32px -18px #3c2c1438`）。
- 描边一律 **inset box-shadow ring**（`inset 0 0 0 1px var(--line)`），不用 border，零布局位移。
- 缓动三件套：`--ease-out:cubic-bezier(.23,1,.32,1)`（主）、`--ease-in-out:(.77,0,.175,1)`、`--ease-drawer:(.32,.72,0,1)`。
- 按压微交互：`.t-press:active scale(.97)`、图标钮 `.92`、胶囊 `.96`，时长 .16s。
- 排版：body 14px/1.5；导航 24px/500/-0.01em；h1 32px→移动 26px；卡片题 18px/500。字重只有 400/500 两档。
- 全局细节：`::selection oklch(85%.1 250/.5)`、`:focus-visible oklch(62%.19 255)`、8px 自绘滚动条、hover 效果全包在 `@media (hover:hover) and (pointer:fine)` 里。

## 五、卡片系统（本站最核心的实现）

**单卡 DOM**（`.hit` 空锚点铺满全卡做热区，z 高于内容但低于按钮）：

```
article.card[data-slug][data-category][data-tags][data-order][data-layout=masonry]
            [data-stage="--r:0.8;--mw:720px;--mwt:720px"][data-stage-poster]
├ a.hit[data-open][href="/i/{slug}"]      ← 整卡可点
├ .top > .media[style="aspect-ratio:720/720"]
│    └ video.m[data-video][data-src][poster][preload=none]   ← 无 src！
└ .text[data-frost]
   ├ img.frost（poster 放大 140%、blur(24px)saturate(1.3)、opacity .28 当文字底色）
   ├ h2.title / p.sub（单行省略）
   └ .foot > .labels（「原作视频」+分类）+ .acts > button.copy[data-copy-prompt-for]
```

1. **masonry 是纯 JS 绝对定位，不是 CSS columns**：
   - 列数 = `clamp(1,3,floor((W+24)/304))`，贪心放入「当前最矮列」，容器高度 = 最高列；
   - **末行均衡**：留 `min(6, n-cols)` 张尾巴卡，暴力枚举 `cols^held` 种分配取高度极差最小；
   - **FLIP**：重排前存 `getBoundingClientRect()`，重排后 `el.animate` 420ms `cubic-bezier(.2,.8,.2,1)` 补差值；新卡 260ms 淡入+scale(.97→1)，延迟 `min(i,10)*24ms`；
   - DOM 重排用 **`grid.moveBefore()`**（新 API）+ LIS 最少移动——为的是**视频不重载**；
   - resize 走 ResizeObserver + rAF 合帧，静默重排不动画。
2. **视频懒加载**：`preload=none` + 无 `src`，进视口（IO）才把 `data-src` 赋给 `src`；浮层打开时全局 `pauseVideos()`。
3. **frost 毛玻璃**：卡片文字区的背景就是该卡 poster 图自糊（`position:absolute;inset:-20%;width/height:140%;filter:blur(24px) saturate(1.3);opacity:.28`）——让每张卡文字底色取自作品本身的颜色。这是整站气质的关键一招。

## 六、交互系统（6 个 module 的分工）

| 脚本 | 职责 |
|---|---|
| **Feed.js**（21KB 核心） | masonry、筛选/排序状态机、无限滚动、详情浮层、滚动恢复 |
| Layout.js | 复制提示词/复制代码 + toast、`data-gate` 门禁、peek 悬浮卡、skip 链接 |
| Search.js | `fetch /search.json` 缓存；评分 `标题前缀3>包含2>关键词1` 取 8 条；combobox/listbox 全套 ARIA + ↑↓/Enter/IME 容错；`/` 与 ⌘K 开合 |
| SubscribeDialog.js | email→验证码→done 三态；`POST /api/subscribe`、`/api/verify`；蜜罐 `input[name=website]`；成功后写 `cp_pass` cookie |
| FeedbackDialog.js | `POST /api/feedback`；字数 `Intl.Segmenter` 数字形、上限 2000；失败降级 mailto |
| MobileBar.js | 滚动 `data-scrolled`、clip-path 菜单开合、焦点圈定 |

**筛选/排序状态机**：`{c,t,sort}` ↔ `location.search`，`replaceState`（不 push）不产生历史噪音；改筛选 → 过滤 → LIS 重排 → FLIP → 滚回顶部（smooth）。**一旦筛选就串行拉全所有分页**（无筛选时才走哨兵 IO 无限滚动，`rootMargin:1500px` 预取）。

**详情浮层**（= 详情页本体，`/i/slug` 是同一页加 `data-initial` 的 SSR 直开变体）：
- 打开：内联 `<template data-detail-tpl>` 有内容立即克隆，否则先渲染 skeleton shimmer 再 `fetch /d/{slug}`（8s 超时降级整页跳转）；
- URL：`pushState({detail:slug}, "/i/slug")`，步进 `replaceState`，关闭走 `history.back()`（500ms 兜底）；
- FLIP：桌面从源卡矩形 spring 弹到舞台（`--r` 比例 + `--mw` 宽度原样复用），关闭反向 spring；源卡 `visibility:hidden`；
- 滚动锁：html overflow hidden + main/mbar `inert` + 全局视频暂停；Esc/←→ 键盘导航；`aria-live` 播报「标题，n / m」；
- prompt 文案直接内联在详情按钮的 `data-copy-prompt` 属性里；卡片上的复制按钮 `data-copy-prompt-for=slug` 未命中模板时才 fetch。

**复制门禁**（`data-gate`）：document **捕获阶段**拦截，无 `cp_pass` cookie → stopImmediatePropagation + 弹订阅墙（wall 文案），验证通过后 `cantrip:wall` CustomEvent 还原焦点并 **re-click 原元素** 完成原操作。

**跨页恢复**：`pagehide` 存 `{pages, y}` 到 `sessionStorage["cantrip:feed:*"]`，back/forward 时手动恢复滚动 + 补拉分页。

## 八、值得偷师的设计手法

1. **frost 取色文字底**——用作品自身 poster 糊化当卡片文字背景，每张卡自带氛围且零设计成本。
2. **inset ring 替代 border**——描边不参与盒模型，hover 换描边无布局抖动。
3. **1023px 单断点 + 系统字体**——整站零字体请求，首屏代价极低。
4. **静态 HTML + data-* 钩子 + 事件委托**——没有框架也没有 island，渐进增强的教科书样本。
5. **`--r` 比例变量贯穿卡片与详情舞台**——一处声明，列表 masonry 与详情 FLIP 共用。
6. **pushState 详情 + history.back 兜底**——浮层即路由，返回键行为与用户直觉完全一致。
